# Yosemite painting

The original canvas brush painting and scene animation use a photographic color and landform guide derived from “Tunnel View” overlook showing famous rock formations in Yosemite Valley 03, by EF5 (2025), dedicated to the public domain under CC0 1.0.

Source: https://commons.wikimedia.org/wiki/File:%E2%80%9CTunnel_View%E2%80%9D_overlook_showing_famous_rock_formations_in_Yosemite_Valley_03.jpg
License: https://creativecommons.org/publicdomain/zero/1.0/

The photograph is not displayed on the page. yosemite-guide.jpg supplies material/color samples for procedural painting and foliage. yosemite-painting.webp is a cached canvas painting for immediate initial rendering.

The reference guide is now used only for local authoring and is excluded from deployment. The display and live atlases are generated from the original painted canvas; normal visits never download the guide.

`yosemite-pine-bough.png` is an AI-generated transparent painted bough, created with OpenAI ImageGen using the existing Yosemite painting as its style reference. It replaces the procedural upper branch. The authoring source is excluded from deployment; its repainted pixels are baked into the live foreground atlas.


Current expressive-paint edition: `yosemite-terrain-brush1.webp` and `yosemite-display-brush1.webp`, with the matching `*-brush1` atlases, reconstruct the reference as broad visible brush marks and simplified pigment planes. The CC0 source and its geography remain unchanged. The older dense pixel-detail coats are superseded by the shared `scenes/brush-painting.js` renderer.

Current Yosemite half-size brush edition uses `yosemite-*-brush2.*`, with the same reference provenance and smaller expressive paint marks.

Current cohesive-paint edition uses `yosemite-*-brush3.*`. The bough source is repainted with the shared bristled renderer and pigment sampled from the painted left pine; source provenance remains unchanged.
