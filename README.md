# Postcardfolio

Five living brush paintings for Yash Kalani’s portfolio:

- Home: Yosemite.
- Projects: Hawaiʻi Volcanoes.
- Experience: Great Sand Dunes.
- Writing: Olympic.
- About: Sleeping Bear Dunes at sunset.

Plain HTML, CSS and JavaScript. Run `npm run dev` and `npm run check`. Playwright QA and baking commands are documented in [LANDSCAPE_PLAYBOOK.md](LANDSCAPE_PLAYBOOK.md), alongside the five scene briefs and exact image credits.

Live at https://postcardfolio.vercel.app/ and https://yash.kalani.name/postcardfolio/. Preserve the main portfolio’s proxy routing. Normal visits load finished paintings and prebuilt live layers; photographic guides are local authoring assets.
